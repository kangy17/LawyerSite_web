# LawyerSite_web
Lawyer Website — это веб-сайт юридических услуг, созданный с использованием **React** и **Vite**.
Проект представляет собой адаптивный сайт адвоката с информацией об услугах, визуальным оформлением в тематике юриспруденции и формой обратной связи.
Форма отправляет данные через **PHP (`submit.php`)**, после чего информация сохраняется в базе данных **MySQL**, размещённой на **InfinityFree**.

> ⚠️ **Обратите внимание:** Frontend проекта разработан на React.  
> Серверная обработка формы выполняется отдельно через PHP-файл `submit.php`.

> 🌐 Рабочая версия сайта размещается на хостинге **InfinityFree** [http://lawyersite.free.je](http://lawyersite.free.je) с подключенной серверной базой данных MySQL.

***React + Vite + JavaScript + CSS + PHP + MySQL.***

## 📨 Форма обратной связи
На сайте реализована форма, позволяющая пользователю отправить обращение.
<br>Файл submit.php (расположен в директории проекта на InfinityFree) выполняет серверную обработку формы:
<br>Получает данные формы.
<br>Подключается к MySQL.
<br>Обрабатывает полученную информацию.
<br>Сохраняет заявку в базе данных.
<br>Возвращает результат отправки.

## 🚀 Запуск проекта
### Шаг 1. Установка Node.js
<br>Для запуска React-приложения необходимо установить Node.js.
### Шаг 2. Клонирование репозитория
Склонируйте репозиторий:
<br>git clone https://github.com/kangy17/lawyersite_web.git
<br>Перейдите в папку проекта:
```
cd lawyer-site
```
### Шаг 3. Установка зависимостей
Установите необходимые npm-пакеты:
```
npm install
```
### Шаг 4. Запуск React
Запустите Vite development server:
<br>npm run dev
<br>После запуска Vite покажет локальный адрес, например:
<br>http://localhost:5173/
<br>Откройте его в браузере.

## 🏗 Production-сборка
Для создания production-версии выполните:
```
npm run build
```
<br>После этого будет создана папка:
```
dist/
```
<br>В ней находится готовая собранная версия React-приложения.

## 🌐 Размещение на InfinityFree
При публикации необходимо учитывать, что React и PHP выполняют разные задачи.
### React
После выполнения:
```
npm run build
```
<br>получается production-сборка:
```
dist/
```
Основные файлы:
```
dist/
├── index.html
├── assets/
└── ...
```

### PHP
Файл:
```
submit.php
```
должен находиться на PHP-сервере и иметь возможность подключаться к MySQL.
<br>
Примерная структура файлов на хостинге:
```
htdocs/
│
├── index.html
├── submit.php
│
├── assets/
│   ├── ...
│
└── images/
    ├── hero.png
    └── courtroom-phoenix.png
```
> ⚠️ Конкретная структура может отличаться в зависимости от того, как именно была настроена загрузка production-сборки на InfinityFree.
